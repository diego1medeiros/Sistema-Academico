# 🎓 Sistema Acadêmico

Sistema desenvolvido para gerenciamento acadêmico utilizando Java, Spring Boot, JSF e PrimeFaces.

## Arquitetura

```
Sistema-Academico
│
├── sistema-academico-backend
│
└── sistema-academico-frontend
```

## Tecnologias

### Backend

- Java 21
- Spring Boot
- Spring MVC
- Spring Data JPA
- Hibernate
- PostgreSQL
- Flyway

### Frontend

- Java 21
- JSF
- PrimeFaces
- CDI

### DevOps

- Docker
- Docker Compose
- GitHub Actions

## Funcionalidades

- Cadastro de Alunos
- Cadastro de Cursos
- Cadastro de Disciplinas
- Cadastro de Turmas
- Controle de Matrículas
- Dashboard
